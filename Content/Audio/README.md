# Audio Content

Generated by the Audio Engine (`Mikester9000/Audio-Engine`).
See `docs/ASSET_PIPELINE.md` for export commands and format details.

Expected runtime files:
- `bgm_field.ogg`   — background music (OGG Vorbis, 44100 Hz)
- `sfx_attack.wav`  — attack sound effect (WAV 16-bit PCM, 44100 Hz)

To import after exporting:
    python tools/import_assets.py --engine audio --src /path/to/audio_export
