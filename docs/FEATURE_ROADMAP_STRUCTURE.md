# Feature Roadmap Structure (How to Plan Safely)

## Planning model
- Use vertical slices.
- Build smallest playable/testable version first.
- Do not build final complexity first.

## Milestone template
1. **Goal outcome**
2. **Minimum playable slice**
3. **Files/systems touched**
4. **Acceptance criteria**
5. **Deferred follow-ups**

## Example: Combat
- Slice 1: basic attack + enemy hit feedback
- Slice 2: dodge + enemy attack telegraph-lite
- Slice 3: target clarity + pacing polish

## Example: Exploration
- Slice 1: landmark-led navigation in one region
- Slice 2: discovery hooks and optional points
- Slice 3: richer region contrast

## Example: UI
- Slice 1: readable combat HUD
- Slice 2: tactical menu clarity
- Slice 3: style polish

## Example: World
- Slice 1: stable cell transition/readability
- Slice 2: region identity pass
- Slice 3: content density improvements

## Example: Quests
- Slice 1: simple authored objective flow
- Slice 2: optional side content hooks
- Slice 3: stronger event pacing
