# UI Presentation Style (Target Direction)

See also: [UI_VISION.md](./UI_VISION.md), [FINAL_FANTASY_FEEL.md](./FINAL_FANTASY_FEEL.md).

## Core direction
- FF-inspired elegance with modern action readability.
- Combat clarity first, decoration second.

## Style split (intentional)
- Fast gameplay: minimal modern HUD.
- Menus/dialog: framed classic JRPG panel language.

## Menu hierarchy
- Primary actions prominent.
- Secondary/support actions grouped and quieter.
- Keep decision depth readable under pressure.

## Panel styling
- Clean framing, strong text contrast, controlled accent colors.
- Decorative detail should never hide information hierarchy.

## Minimap/HUD clarity
- Stable screen anchors.
- Low clutter and consistent icon language.
- Target/health/action state visible at a glance.

## Feedback style
- Dramatic but readable.
- Strong state feedback without visual spam.

## Avoid HUD clutter
- Do not stack too many simultaneous alerts.
- Do not use constant animated noise for all elements.
