# Engine Roadmap
# Target: FF7-style visuals + FF15 / FF7 Remake-inspired action gameplay

This document is the working task list for the engine.
Use it as the default "what should be done next?" reference.

---
## 0. Project Vision

### Visual target
- Stylized JRPG presentation
- FF7-inspired readability and silhouettes
- Simpler geometry and materials than modern AAA realism
- Strong shape language over asset density
- Low-poly / mid-poly friendly pipeline

### Gameplay target
- Real-time action combat
- Responsive movement
- Dodge / attack / combo flow
- Enemy targeting and lock-on
- Third-person camera
- Party-system support later

### Engine priority rule
When choosing between two tasks:
1. Prefer cleaner extensible architecture
2. Prefer gameplay readability over rendering complexity
3. Prefer systems that unlock future work
4. Defer high-end rendering until actor/gameplay structure is stable
